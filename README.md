
# Real-Time Motion Detection

A real-time motion detection application built using
Python and OpenCV.

## Features
- Live webcam processing
- Background subtraction
- Motion region detection
- Bounding box visualization
- Noise filtering

## Technologies
- Python
- OpenCV

## Installation

```bash
py -m pip install opencv-python
```

## Run

```bash
py motion_detector.py
```

Press Q to quit.
